TripLog이 Google에 보내는 주소와 Google Cloud Console에 등록한 Redirect URI가 다를 때 납니다. 아래 값을 그대로 등록하세요.

Google Cloud Console 순서

  1. API 및 서비스 → 사용자 인증 정보
  2. OAuth 2.0 클라이언트 ID (웹 애플리케이션) — 위 client_id와 같은 항목 선택
  3. Authorized JavaScript origins에 추가: https://triplog.my (경로 없음, https)
  4. Authorized redirect URIs에 위 Redirect URI 한 글자도 틀리지 않게 추가
    • onrender.com 주소만 있으면 mismatch 발생
    • www., 끝 /, http:// 사용 금지
  5. 저장 후 5~10분 기다렸다가 시크릿 창에서 Google 로그인 재시도

Render Environment

  • GOOGLE_CLIENT_ID = 위 OAuth 클라이언트 ID
  • GOOGLE_CLIENT_SECRET = 같은 클라이언트의 Secret
  • GOOGLE_REDIRECT_URI = …
  • APP_URL = https://triplog.my
