카카오 KOE006 (Redirect URI) 해결

KOE006은 카카오 개발자 콘솔에 Redirect URI가 없거나, REST API 키가 다를 때 납니다. TripLog 서버는 아래 주소만 사용합니다.

JavaScript 키가 아니라 REST API 키에 등록해야 합니다.

카카오 개발자 콘솔 순서

  1. developers.kakao.com 로그인
  2. 앱 해수의 여행일지 선택
  3. 제품 설정 → 카카오 로그인 → 활성화 ON
  4. 앱 → 플랫폼 → Web → 사이트 도메인 https://triplog.my
  5. 앱 → 플랫폼 키 → REST API 키 (위 client_id와 완전히 동일한 키)
    • 「Redirect URI」에 위 Redirect URI 한 글자도 틀리지 않게 추가
    • http://, www., 끝 /, onrender.com 주소 사용 금지
  6. 저장 후 1~2분 기다렸다가 시크릿 창에서 다시 로그인

「카카오 로그인에 실패했습니다」가 뜰 때

인가(KOE006)는 통과했지만 토큰 교환에서 실패한 경우입니다.

  1. REST API 키 → Client Secret: 「사용」이 ON이면 Render에 KAKAO_CLIENT_SECRET을 콘솔과 동일하게 넣으세요. OFF면 Render에서 해당 변수를 삭제하세요.
  2. Render KAKAO_REDIRECT_URI = 위 Redirect URI와 완전히 동일한지 확인
  3. 로그인을 오래 두었다면 다시 「카카오」 버튼부터 시도
